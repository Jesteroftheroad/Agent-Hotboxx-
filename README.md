# HOTBOXX Content Engine

A weekly system for HOTBOXX, Silchar: the manager uploads photos and videos, and Claude with Higgsfield turns them into trend-backed Instagram Reels, captions and hashtags.

| File | Purpose |
|---|---|
| `SETUP.md` | Setup guide (Tier 1: Claude web app, Tier 2: Claude Code autopilot) |
| `SKILL.md` | Installable Claude Skill: brand, rules, weekly workflow, menu |
| `MASTER_PROMPT.md` | One-shot prompt for any Claude chat, no setup needed |
| `viral-formats.md` | Library of viral food-reel formats adapted for HOTBOXX |
| `durga-puja-menu.md` | Price source of truth (Puja menu + everyday anchors + promos) |
| `CLAUDE.md`, `.claude/skills/`, `.mcp.json` | Tier 2 Claude Code setup (agent instructions, skill, Higgsfield + Apify MCPs) |
| `brand/avatar.md` | AI host avatar concepts and lock record |
| `inbox/` | Drop the manager's raw photos/videos here |
| `weeks/<date>/` | One folder per weekly run: trend research, reel briefs, hooks, captions |

Start with `SETUP.md`.
